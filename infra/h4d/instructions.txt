Advanced Deployment Instructions
================================

Terraform group 'primary' was successfully created in directory isx-h4d/primary
To deploy, run the following commands:

terraform -chdir=isx-h4d/primary init
terraform -chdir=isx-h4d/primary validate
terraform -chdir=isx-h4d/primary apply

Destroying infrastructure when no longer needed
===============================================

Automated
---------

gcluster destroy isx-h4d

Advanced / Manual
-----------------
Infrastructure should be destroyed in reverse order of creation:

terraform -chdir=isx-h4d/primary destroy
